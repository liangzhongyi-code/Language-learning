# 雲端同步程式碼審查

審查日期：2026-11-13。範圍：`51d36b9` 至 `feature/add-cloud-sync` 的整合工作樹。檢查入口、資料流、條件式寫入、角色權限、移除行為、重試與文件同步。

## 已驗證的修正

- 登入回呼先核對發起瀏覽器的短效 cookie，再消耗一次性 state。跨分頁換帳號時，快照、登出、刪除及管理請求核對原帳號。
- 快照在 D1 交易內再核對 session、資格、版號與頻率。已撤銷的請求不能重建快照；管理員降級後，晚到的新增成員請求也不會寫入。
- 手動覆蓋只使用確認時的本機資料世代與雲端版本。預覽確認前再查雲端版本；本機還原交易本身也檢查本機版本。保存完成後立刻記同步基準及通知，不等待下一次網路查詢。
- 舊站以代碼匯出再還原實測，未發出雲端或 Google 請求。APP 資源測試確認網站專屬頁面不會成為離線包的缺檔連結。

## 上線前待驗

- 用正式 Cloudflare 與真實 Google 帳號驗證 OAuth 回跳、白名單與三種角色，再用兩台實體裝置確認衝突處理。
- 以接近 8 MiB 的快照測正式環境的下載效能與 CPU。若超出實際方案上限，再評估設計中的替代方案。
- 本機還原與遠端帳號檢查分屬瀏覽器和伺服器，無法組成單一交易。已縮短確認與寫入之間的時間；雲端請求持續按 session 與原帳號核對。

規格的 50 個雲端情境均有任務映射。最終本機驗證通過：Node 1,458 項、Chromium 31 個套件及 3 項執行器檢查、本機 Worker 31 個套件，另有使用假 Google 與 D1 的雙裝置流程。正式環境仍待 T23 驗收。
