## 目的

## 已決定事項（2026-10-22，使用者決定）
1. **保留分かち書き空格**：匯入的 JLPT 題保留上游 N5 的詞間空格，與 N5 考卷一致；既有題庫不改。
2. **獨立 JLPT 題源**：不併入既有「選擇題」，保留 JLPT 區段與問題號，可按問題號分開練。
3. **只寫繁中解說**：不保留上游英文或印地文解說；`note` 一律繁中，與既有慣例一致。
4. **N5 閱讀下限 60 字**：屬第三批（閱讀匯入）的 schema 變更，本批不實作，只先記錄決定。

## 不在本批
- ★排序（bunpou 問題2）與 `questions.json` 排序題：第二批，改走 `practice.js` 的 `reorder` 並列出所有合法語序。
- `questions.json` 四選一與打字題：第二批，需與本批去重。
- 讀解與閱讀 100 篇、N5 閱讀下限 60 字：第三批。
- 文章的文法（bunpou 問題3）、聽力：暫緩，沒有對應題型。
- VOICEVOX 語音與 KanjiVG：不收。
- 每日學習：本批只接自由測驗，不排入每日清單。
- 英文：不提供 JLPT 題源。
