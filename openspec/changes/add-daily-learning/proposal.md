# 每日學習與個人化複習

> add-daily-learning · 2026-10-05 · 完整模式
> 2026-10-05 設計已核准；tasks 已建立待第二道核准，尚未修改生產程式。

## 目的
讓使用者一開啟網站就知道今天該複習哪些字、學哪些新字，關閉後可以接續。新字選擇、複習頻率與每日工作量分開管理。

## 現況與擴充
現有 Leitner 為 1／3／7／16／35 天；紀錄只有 sourceId 的 n／w／box／last／due。整局結束才保存，沒有逐次歷史或固定每日清單。範圍篩選後仍隨機抽題，少於四題時 UI 不開放該複習範圍。本次擴充而非重新發明已有功能。

## 交付分期
- A：今日單字清單、每日新字額度、先教再考、逐題保存及續答、真實複習日誌、改良 Leitner。
- B：正式接上本機 FSRS 預設參數排程與漸進遷移；不是只預留開關。自動訓練個人參數另立後續需求。
- APP：與已核准的 add-native-app-packaging 共用資料介面。網站先交付，不等待 Mac 或原生工具鏈。

## 範圍
- 英日文每日單字；日文遵守 N1～N5 隔離。保留自由測驗全部題型、問題回報、漢字模式與外觀。
- 新字預設每日 5，可選 0／5／10／20；複習每段預設 20，積欠另顯示且可繼續。數字是產品預設，不宣稱科學最佳值。
- 自由測驗也記錄實際事件，但句子作答不能將所有包含的單字判為已學。每日情境／閱讀課表不在首版。
- 免登入、離線可運算、不新增雲端同步或分析服務、不新增未知授權的字頻資料集。題庫順序不宣稱是常用度排名。

## 影響與設計入口
新增純核心清單、事件 reducer、排程 adapter，調整測驗／首頁／備份／統計。網站學習儲存改用 IndexedDB 交易；偏好可留 localStorage；APP 以 SQLite 實作同一非同步介面。
