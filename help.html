使用教學

四個學習模組各自在幹嘛、什麼時候該用哪一個，以及色塊拆解怎麼讀。

完全沒學過日文的話，先看 日文入門手冊——那裡講的是「為什麼日文長這樣」，這裡講的是「這個網站怎麼操作」。

◐ 畫面顯示

點選導覽列右上角「外觀」，在「顯示模式」選擇深色或淺色。

「顯示模式」中勾選的選項代表目前使用的模式。選擇會存在瀏覽器並跟著備份資料走， 所以重新開啟網站或匯入自己的備份後，不必再設定一次。

「外觀」提供經典藍、午夜藍、森墨綠與暖砂棕，搭配純色、柔光或微塵背景。 點選就會立即套用；每套配色都支援深色與淺色，不影響答對／答錯的辨識色。

開啟「降低特效」會關閉動態、微塵與磨砂模糊；系統已設定「減少動態」時也會自動降低特效。 測驗與閱讀卡片保持實心底色。選單可按關閉鍵、Escape，或點外側收合。

桌機版會使用較寬的內容區與較大的閱讀字級；手機版則保留單欄和 44px 以上的觸控範圍，不需要左右捲動。

🔊 發音

英文是 26 字母與音標，日文是 104 個假名。

點卡片就會唸出來。英文字母卡上另外有一個例字，例字旁邊的喇叭會唸整個單字而不是字母本身。

日文的假名分成清音、濁音、半濁音、拗音四個區塊，可以各自收合。濁音格子會標出它的清音來源 （が ← か），因為濁點的規則就是「清音加兩點」，擺在一起看比死背快。 右上角可以切換平假名、片假名或兩者並列，羅馬拼音在三種模式下都會一直顯示。

什麼時候用它：剛開始學，或看到某個假名念不出來的時候。這是唯一不需要先懂任何單字就能用的模組。

📇 單字

可以搜尋、依主題篩選，每個字都能朗讀。

搜尋框同時比對中文、外語寫法、假名讀音、羅馬拼音四個欄位，所以查日文的「雨」時， 打 雨、あめ、ame 都找得到，大小寫也不影響。

主題分類（食物、交通、天氣⋯）不只是給你篩選用的——測驗的干擾選項會優先從同一個分類裡挑， 所以題目才不會出現「蘋果」的選項是 apple / run / beautiful 這種一眼就猜到的組合。

什麼時候用它：測驗前想先掃一遍，或測驗後想針對某個主題補強。

🧩 文法句型

這是這個網站的重點。

每個句子被切成幾個語意區塊，畫成上下兩排。下面是一個真實的例子：

上排 · 中文語序
我主詞
今天時間
去打動詞
羽毛球受詞
I主詞
play動詞
badminton受詞
today時間
下排 · 英文語序

怎麼讀這張圖：

  • 上排是中文的說法，下排是外語的說法。同一個顏色代表同一個語法角色——藍色永遠是主詞、紅色永遠是動詞。
  • 虛線框加上「語序不同」標籤，代表這一塊在兩種語言裡的位置不一樣。上面這句的「今天」在中文排第 2 個， 到了英文卻跑到最後——這就是英文時間副詞的習慣。
  • 連接線把兩排的同一塊連起來。線交叉，就代表語序換了。文法頁的句型篩選下方有「顯示連接線」開關，覺得太花可以關掉。
  • 點下排的任何一塊，只會唸那一小段；點整句旁邊的喇叭才唸整句。

日文還會多出一種灰色的窄塊：助詞（は、を、で⋯）。它們只出現在下排， 上排完全不顯示——因為中文根本沒有對應的詞。硬要在中文排擠一格出來反而會讓人以為中文也有這個成分。

什麼時候用它：當你單字都認得、但句子就是拼不出來的時候。問題通常不在字，在語序。

🎯 選題測驗

六種題型，各練不同的東西。

開始前先選題型：

  • 單字／句型／混合——四選一，可選中翻外、外翻中或每題隨機
  • 填空——句子挖掉一到三塊，從旁邊的候選詞挑回去。候選詞一定比空格多， 並且盡量放同一個語法角色的字（助詞的空格配別的助詞），不讓你用刪去法蒙混； 同角色的字不夠時會拿別的角色來補，這種時候候選詞會比平常好認一些
  • 情境（僅日文）——同樣的意思，換個場合就要換個說法。 考自稱、稱呼對方、敬語三體系，以及對外提到自家人一律不加敬稱的內外分際
  • 閱讀——一篇短文連出三到四題，問法與選項的語言可以切換： 中文版純粹測讀懂了沒、外語版連題目都要先讀懂（接近 JLPT 讀解的實戰形式）

日文測驗還有一排「JLPT 難度」：可以選全部，或只練 N5、N4、N3、N2、N1。 選了單一級別後，題目、四選一的干擾選項、填空候選詞都只會來自同一級， 不會拿 N1 的字混進 N5 題。級別旁會顯示目前題型的題數；不足四題時會呈灰色、不能選。

目前單字與混合題涵蓋 N5～N1；句型與填空主要是 N5～N3； 情境及閱讀主要是 N3～N1。這是現有題庫分布，不是篩選器漏資料。

再選題數：10 題、20 題，或目前級別／範圍內的全部題目。

填空題怎麼操作

兩種方式都行：點候選詞再點空格，或反過來先點空格再點詞；桌機還可以直接把詞拖進空格。 點已經填好的空格會把字收回來，點已用掉的候選詞也會。 鍵盤可以按數字選詞（自動落進第一個空格）、Backspace 收回最後放進去的那一格（照放的先後，不是照位置）、Enter 提交。

要全部填滿才能提交，提交後每一格會標出對錯，填錯的格子右邊直接顯示正解。

其他題型

選了答案就立刻鎖定，答錯時會同時標出「你選的」和「正解」。不提供回上一題， 因為能改答案的正確率沒有意義。可以按鍵盤 1–4 選項、Enter 下一題。

閱讀題的短文在同一篇的第二題之後會自動收起來，點標題可以再展開回頭查； 中文翻譯要作答後才出現，而且預設收合——先看到翻譯，同一篇後面幾題就沒得考了。

漢字要不要出現（日文）

日文測驗的設定畫面有一排「漢字」按鈕，三選一。母語是中文的人看到「寿司」不必會唸日文 就知道是壽司，那一題考的其實是漢字而不是日文——這排按鈕就是用來決定要不要把漢字擋掉。切過就記住。

  • 照常顯示——日文平常的寫法，也是預設
  • 標在假名上——讀的是假名，漢字用小字標在上面。 跟日文書上的振り仮名剛好相反（那是假名標在漢字上）， 所以主要讀的是假名，想不起來怎麼唸時抬頭就看得到漢字。適合邊練邊記寫法
  • 只顯示假名——漢字完全不出現，考的是「這個詞怎麼唸」。要真的考自己就用這個

本來就沒有漢字的詞（コーヒー）維持原樣，不會被硬轉成平假名。 朗讀送出去的一直都是假名，所以選哪個都不影響發音。

只對單字、句型、混合、填空四種題型有效。 情境題的四個選項是連場合一起寫死的、閱讀題的短文沒有假名版，都換不掉； 選了這兩種題型時那排按鈕會收起來，並顯示一行說明。

選了閱讀題時，設定畫面會多出一個「問法與選項的語言」開關，切過就記住。 兩種模式的差別不只是難度：中文版答錯就是短文沒讀懂、原因很單純， 外語版則分不出是短文沒讀懂還是題目沒讀懂——想確認自己的閱讀能力用中文版， 想模擬考場就用外語版。

只練易錯、只練今天該複習

練過幾局之後，設定畫面會多出一排「範圍」：

  • 只練易錯——只出你錯過而且還沒練熟的題目，錯得最兇的優先（錯誤率一樣時，錯得次數多的排前面）。 舊版摘要仍依盒號判斷；已轉換 FSRS 的字以能力是否練熟判斷，不再承諾固定答對三次就畢業
  • 今天該複習——依各能力的到期時間出題；FSRS 使用預設參數安排下一次複習， 答錯或用了提示不當作無提示答對

範圍是套在題型上的篩子，不是新的題型——所以「易錯的填空題」是成立的組合。 干擾選項一律從完整題庫抽，不會因為範圍只剩五個字就變成用刪去法就能全對。

第一次來看不到這一排是正常的：還沒有紀錄，那兩個選項出不了題。 練過幾局它自己會出現。

每局結束會列出所有答錯的題目：題面、你選的、正解，句型與填空題還會附上那句的語序說明。 成績會依「語言 × 題型」分開累加，顯示在語言首頁。

發現題目有問題

每一道題目下方都有「這題有問題？產生回報代碼」。展開後可以填寫問題描述， 再按「複製回報代碼」。把以 langissue1: 開頭的代碼貼給我， 就能定位題目 ID、當時的難度與顯示設定，也能看到你當時遇到的題面與選項。

回報代碼只包含目前這一題和你輸入的說明， 不包含其他題目的答題紀錄、總分或整份複習排程，也不會自動上傳。

逐題保存：已提交且顯示「已保存」的答案會保留，半局仍累計答題數，但不加完成局數。 重新開啟測驗頁可按「繼續」接續同一份題序；未提交的填空輸入不保留。保存失敗請按「重試保存」，成功前不能換題。

📅 今日學習、練習、單字簿與歷程

每個語言的導覽列多了「今日」「練習」「單字簿」「歷程」四頁。

今日學習

每天一份固定清單：先複習到期的字，再學新字。新字預設每天 5 個（可改 0／5／10／20）， 英日文各自一份額度，換級別不會多發新字。新字會先出教學卡（讀音、意思、例句）， 按「開始測驗」才算開始學這個字；不想學可以按「今天略過」或「我已經會了」。

每答一題就保存，畫面出現「已保存」才會放行下一題；關掉頁面回來會從下一題繼續。 答錯的字在同一段裡會再出現一次補強（不會影響長期的複習間隔）。 到期的字太多時，超過的部分排在「下一段」，完成第一段後可以選擇繼續。

單字的到期能力會用對應題型複習：例如拼寫仍要輸入答案、聽力仍要聽後作答，不會全部改成四選一。 沿用同語言、同級的人工題庫；若尚無相符題目，會說明原因並保留排程，不視為已完成。 每日頁的聽力播放失敗時可以重試或回清單，尚未作答的題目仍保留。

拼寫與聽力練習

拼寫、假名輸入（日文）、聽力、聽寫、拼組、句子重組、語境詞性七種題型，每種能力分開記錄—— 選擇題答對不代表拼得出來。用了「提示」的題目，排程會當作還需要再練。 日文目前只提供 N5 的題目，其他級別會直接說明尚未補齊，不會偷偷拿別的級別湊題。

聽力與聽寫只使用裝置上的離線語音，不會把題目送到雲端語音； 沒有離線語音時這兩種題型會停用並說明。播放失敗不算答錯，可以重試或跳過。

單字簿

「收藏」是固定的一本，另外可以自建最多 100 本。每個字可以寫筆記（最多 2,000 字）、標記「想學」 （新字會優先排進今日清單），或「自評已會」（不再當新字介紹，但標示為未驗證，之後答錯會自動解除）。 單字簿可以單獨匯出成檔案分享給別人，匯入時會先預覽同名與筆記衝突，不會動到你的學習紀錄。

學習歷程

學習日曆、連續天數與成就，只算真正作答過的題目，打開網頁不算。斷了連續天數不會抹掉累計。 這一頁也能設定朗讀、音效、震動與安靜模式，以及每日提醒—— 網頁版的提醒只在網頁開著時有效，關掉網頁就不會提醒。

💾 紀錄會存多久

存在你自己的瀏覽器裡，沒有帳號也不上傳。

成績與學習紀錄都存在瀏覽器的本機資料庫（IndexedDB）裡，每次保存都是一筆完整的交易—— 不會出現只存一半的狀態。關掉視窗、重開機都還在， 這一點常被誤會——它不是那種關掉就沒的暫存。舊版存在 localStorage 的紀錄會在第一次打開新版時自動搬過來，原資料保留不刪。

真正會讓紀錄消失的是這四件事：

  • 清除瀏覽器的網站資料 / Cookie
  • 用無痕視窗練習（那一次的紀錄關掉就沒了）
  • 換一台裝置，或在同一台換一個瀏覽器
  • 裝置儲存空間嚴重不足時被系統清掉（少見）

所以全站首頁最底下有「備份與還原」：下載檔案會把統計、逐題紀錄、每日清單、作答歷程、 單字簿、筆記與偏好設定打包成一個 JSON 檔存下來；換裝置時在新的瀏覽器上選擇備份檔就能倒回去。 還原會整組替換（不合併），確認前會先把目前的紀錄存成還原點（最多三份）， 還原錯了可以在同一個面板按「回到這裡」。舊版的備份檔也能匯入。

手機上檔案會存到哪裡

裝置下載的檔案在哪
Android「下載」資料夾，用檔案管理員或 Files by Google 找得到
iPhone / iPad「檔案」App → 「下載項目」（在 iCloud 雲碟或「我的 iPhone」底下，看 Safari 設定）
桌機瀏覽器的預設下載資料夾

手機建議直接用「分享…」而不是下載。 支援檔案分享的瀏覽器會多一顆「分享…」按鈕（多數手機瀏覽器，以及較新的桌機 Chrome / Edge / Safari；Firefox 目前不支援）， 按下去就是系統的分享面板——可以直接 AirDrop 到另一台裝置、傳到 LINE 或訊息、寄給自己、或存進雲端硬碟。 對方收到的檔案可以直接在這一頁匯入，不必先想辦法把它從「檔案」App 搬出來。 分享出去的檔案副檔名是 .txt（部分瀏覽器不放行 .json 的分享），內容與下載的那份完全相同，匯入時兩種都收。

匯入時按「選擇備份檔」會開啟系統的檔案選擇器，iPhone 上可以從 「檔案」App、iCloud 雲碟、甚至剛收到的訊息附件裡挑。

不想碰檔案？用一串代碼

按「複製代碼」會把整份紀錄壓縮成一串文字並複製到剪貼簿（畫面上也會顯示出來， 複製不成功的話可以手動全選）。把它貼到訊息、備忘錄、郵件——任何能貼文字的地方； 在另一台裝置上把那串文字貼進同一個框、按「讀取代碼」，就會進入和檔案匯入一樣的預覽與確認。

長度看紀錄多少。用幾週大約幾千字，多數通訊軟體一則訊息放得下； 練了幾千個字的紀錄會到幾萬字，聊天軟體會拒收或截斷——那時貼備忘錄或寄郵件給自己， 或改用檔案。畫面上會直接告訴你這串放不放得進訊息。

代碼開頭是 langlearn1:，後面是壓縮過的內容 （少數較舊的瀏覽器產出的是 langlearn0:，沒有壓縮但一樣能讀）。 貼錯東西會直接說「這不是本站的代碼」；少複製一段會說「不完整」。 通訊軟體塞進去的換行沒關係，讀取時會自己去掉。

一個限制：較舊的瀏覽器（iOS 16.3 以前的 Safari、Firefox 112 以前） 讀不了壓縮過的代碼——新手機產的代碼貼到舊手機會被告知「請改用檔案匯入」。 反過來沒問題：舊手機產的代碼新手機都讀得了。

匯入不會直接覆蓋——先讓你看到那個檔案裡有什麼（匯出時間、各有幾筆）， 按下確認才寫入。選錯檔案時會直接告訴你「這不是本站的備份檔」，並且不動任何資料。

沒有做自動雲端同步。那需要登入與第三方服務， 會讓這個網站失去「不連線、沒有帳號」的特性——目前的取捨是留住那個特性，用手動備份換跨裝置。

☁️ Google 雲端備份（選用）

手動、多份、可選擇還原；不登入也能照常學習。

首頁的「Google 雲端備份」在網站管理者設定 OAuth 用戶端 ID 之前會顯示「尚未設定」， 這時網站完全不會連線到 Google。設定之後：

  • 按「連接 Google 帳號」才會開啟 Google 的授權視窗；只要求「應用程式專用資料夾」與 email（用來顯示你連的是哪個帳號），看不到你雲端硬碟裡的其他檔案。
  • 每按一次「備份到 Google」就新增一份快照，不會覆蓋或刪除舊的，兩台裝置各自備份也不會互蓋。
  • 還原時先選一份、下載後在「學習紀錄」面板預覽，確認才替換；和檔案匯入一樣會先存還原點。
  • 網路斷掉導致結果不明時，畫面會說「無法確認」，重試會先查詢同一份備份；但雲端查詢可能有延遲，仍可能留下重複快照，不保證只有一份。
  • 授權只存在這個分頁的記憶體裡，不寫進瀏覽器儲存、網址或備份檔；關掉分頁或按「中斷連接」就失效。

雲端備份沒有額外加密；Google 帳號的空間會被這些快照占用，目前沒有自動清理。

網站管理者：怎麼設定

在 Google Cloud Console 建立專案並啟用 Google Drive API，設定 OAuth 同意畫面與測試使用者， 建立「網頁應用程式」類型的 OAuth 用戶端 ID（已授權的 JavaScript 來源填網站的 origin，例如 https://<帳號>.github.io，不含 repo 路徑），把用戶端 ID 填進 assets/js/config/google.js 的 webClientId。不需要也不要放 Client Secret 或 API key。 詳細步驟見專案的 docs/google-backup-setup.md。

❓ 聽不到聲音怎麼辦

發音功能用的是瀏覽器內建的語音合成，網站本身沒有夾帶任何音檔，所以不用等下載、離線也能用。 代價是聲音由你的作業系統或瀏覽器提供——網頁沒有任何辦法自己安裝語音， 這也是為什麼英文通常有聲音（Windows 裝英文時就一併裝了英文語音）而日文常常沒有。

這台裝置現在有什麼語音

怎麼裝日文語音

Windows 11 / 10最常漏掉一步
  • 設定 → 時間與語言 → 語言與地區
  • 按新增語言，選「日本語」
  • 裝完之後點進該語言的語言選項，找到「語音」項目按下載

只裝語言包不夠，一定要確認裡面的語音（Speech）元件也裝了—— 這是最常漏掉的一步，也是「明明裝了日文卻還是沒聲音」的原因。

Android
  • 設定 → 系統 → 語言與輸入 → 文字轉語音輸出
  • Google 文字轉語音引擎 → 安裝語音資料 → 日本語
iPhone / iPad / Mac
  • 設定 → 輔助使用 → 朗讀內容 → 語音
  • 加入「日本語」並下載

裝完重開瀏覽器就好。網站會在語音清單更新時重新偵測， 頁面上那則「可能沒有安裝語音」的提示會自己消失，不用做別的事。

如果整個瀏覽器都不支援語音合成，所有喇叭按鈕會直接隱藏，其餘內容照常可讀。

🔒 你的資料

沒有帳號、沒有後端、預設沒有任何對外連線。你的紀錄只寫在這台裝置的瀏覽器裡—— 包含答對率統計、逐題的作答與答錯次數、複習排程、每日清單、單字簿與筆記。這些資料不會離開你的裝置， 也沒有任何人（包括我）看得到。唯一的例外是你自己按下「Google 雲端備份」的連接與備份（需網站已設定，見上一節）。

換一台裝置預設就是全新的；要把紀錄帶過去，用首頁的 「備份與還原」匯出成檔案再匯入（見上一節）。

語言首頁的「清除紀錄」會清掉全部。 統計、逐題的作答紀錄、複習排程、每日清單、單字簿、筆記、成就與還原點，一次全刪，而且英文與日文一起（外觀等偏好會保留）。 統計歸零之後還能再練回來，但複習排程是累積出來的、刪掉就回不去—— 按之前先匯出一份會比較安心。
