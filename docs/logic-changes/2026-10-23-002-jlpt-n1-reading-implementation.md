## 規則、邊界與取捨

- **工具錯誤（實作中發現並修正）**：`--check --types X` 原本會把其他題型排除表裡的組誤報成「上游沒有」。現在改為用組 id 前綴判斷題型，不在比對範圍的直接略過，並補上測試。
- **大小估算更正**：設計原估 N1 目錄約 50 萬位元組，實測 819,881 位元組，主要是逐選項解說比預期長。設計 TD7 已追記；這也讓按級別拆檔更有必要。
- **劃線句**：整篇短文的劃線句在同一篇的每一題都會顯示，跟紙本考試一樣。
- **品質**：題目很可能是 AI 產生的；本專案的審查與解說也由 AI 撰寫，未經母語者審查。`CREDITS.md` 與檔頭都已明示。
