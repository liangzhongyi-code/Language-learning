# 雲端同步業務邏輯

最後更新：2026-11-13（Asia/Taipei）。適用於語言學習網站。部署與驗收狀態見 [OpenSpec 任務清單](../../openspec/changes/add-cloud-sync/tasks.md)。

## 入口與本機資料

前端只在 `CLOUD_CONFIG.siteOrigin` 指定的網址啟用本站同步。空設定、舊站和其他網址不會送出同步 API 請求。學習與檔案／代碼備份仍可使用。瀏覽器按網址來源隔離 IndexedDB；跨網址時先從舊站匯出，再到新站確認還原。舊站搬家提示可關閉，狀態不進備份。Google Drive 手動備份與本站同步各自授權。

## 登入與權限

未登入時，新站只用 `GET /api/me` 查詢登入狀態。點擊登入後，Worker 建立有效期 10 分鐘的一次性 state 和 PKCE，以 `__Host-ll_oauth` 綁定發起登入的瀏覽器，並導向 Google。回呼必須帶相符的 cookie；驗證綁定後消耗 state，回跳時清除登入 cookie。Worker 從 Google 換取並檢查身分資料，只接受已驗證 email。預設還要在白名單內；開放模式接受其他已驗證的 Google 帳號。回跳只限本站。

Worker 用 Secure、HttpOnly、SameSite=Lax 的 session cookie 維持登入，效期 30 天，資料庫只保存其雜湊。每次受保護的請求都檢查 session 與角色。寫入請求另核對 Origin。前端將目前帳號帶到快照、登出、刪除及管理請求；帳號換了就拒絕舊分頁的操作。快照與管理寫入在交易內再次核對授權，避免已撤銷的請求繼續寫入。

擁有者可以管理角色、修改暱稱與移除成員。管理員可以新增成員、修改成員或自己的暱稱。成員不能管理名單。新增的人固定為成員；擁有者不能透過後台建立、移除或降級。白名單移除會撤銷受影響帳號的 session；不等於刪除其快照。

## 排程、衝突與還原

同一帳號在 D1 只留最新一份 gzip 學習快照。新裝置雲端空、本機有學習紀錄時可自動上傳；本機空而雲端有資料時，只提供預覽。兩邊都有資料且沒有基準時，要求使用者選擇。同步基準以帳號隔離，另記本機 revision 與 dataEpoch；不放入任何備份。

本機作答後等待最後一次寫入滿 10 秒；頁面隱藏時可提前送出。支援 Web Locks 的瀏覽器在同源分頁之間一次只讓一個分頁處理上傳。上傳帶預期的雲端 revision，版本不同回 409，保留現有快照。壓縮後上限 8 MiB；同帳號最近一小時成功上傳達 60 次時依 `Retry-After` 等待。一般暫時故障依序等待 30 秒、1 分、2 分、5 分，再以 5 分鐘間隔重試。結果不明時先查 revision 與 upload ID，不把未知結果當成功。離線時仍可作答。

雲端較新且本機未變時提示套用；兩邊都變時可用雲端的、用這台的或稍後處理，沒有逐筆合併。本機清除或從檔案、代碼等來源整組還原後，先詢問是否更新雲端。選擇以本機覆蓋後，如果等待上傳期間本機又整組替換，舊確認失效；若雲端版本已變，伺服器拒絕覆蓋。使用者確認雲端預覽時先核對帳號與版本，再以共用還原交易寫入本機並建立還原點；驗證失敗或取消不寫入。還原成功的本機版本用作新同步基準，完成提示不等待背景重新查詢。

## 登出、刪除與回復

登出停止本頁自動上傳，撤銷目前 session，保留本機與雲端紀錄。刪除本站雲端資料會移除自己的快照、session 與使用者資料，保留白名單及本機紀錄。雲端快照沒有端到端加密。部署設定、管理與回滾見 [雲端同步部署手冊](../cloud-setup.md)，並以 [隱私權說明](../../privacy.html) 向使用者揭露保存內容。
