## 規則、邊界與取捨

- **漢字只考讀音**：使用者看得懂繁體，字義多半猜得到。選項是整組讀音（「音 ガク　訓 まな(ぶ)」），
  因為很多字共用單一讀音（日、火 都有 ひ），只給一個讀音會兩個字都對。讀音組完全相同的字（午、語 都只列 ゴ）不會同題出現。
  干擾選項先挑讀音有重疊的字，取自整張漢字表（不受「只練寫法不同的」限制）。
- **漢字例詞**全部取自 N5 單字題庫並逐筆核對讀音；題庫裡只有一個例詞的常見字也收，完全沒有的（田）與 N4 的字不收。
- **文法點排程的單位是文法點**：每次從該點的 2～3 題裡抽一題，記住的是用法而不是那一句。
  選項是手寫的（每題四個、只有一個說得通），不從別的文法點抽。題目標籤只寫「文法」，不寫文法點名稱（寫了就是答案）。
- **閱讀朗讀唸手寫的假名讀音**（`data/ja/reading-kana.js`，逐句含每個漢字片段的讀音），不把漢字原文丟給語音引擎；
  這是閱讀題當初不給朗讀的原因。測驗頁的閱讀題維持原樣。
- **點詞查詢**：從單字題庫找開頭相同、跟句子接下來的字對得最長的詞；後面接送假名時優先動詞與形容詞（出て → 出る）；
  讀音對不上的同形詞不採用（十分 在「十分ぐらい」唸 じゅっぷん，不能查成 じゅうぶん）。查不到（人名、數量詞）就列出片段的讀音與漢字表資料。
- **跟讀**：第一次使用先問要「使用語音辨識」還是「只錄音」，並寫明 Chrome 的辨識會把聲音送到 Google。
  辨識結果同時跟原文寫法與假名讀音比，取較像的，標出沒對上的字；畫面明講「聽得懂不等於發音標準」。
  只錄音時錄音只在分頁記憶體，不上傳、不保存。跟讀**不寫學習紀錄**（辨識受口音、環境、引擎影響，不能當對錯）。
- **跟讀與標假名的選擇不進偏好設定**：備份的偏好欄位是白名單，多一個鍵會讓舊版還原整段失敗。
  跟讀模式存在獨立的 `lang-learn.shadow.v1`（只屬於這台裝置）；標假名每次開頁預設開。
- **文法點整區預設收合**：攤開會把句型拆解推出畫面（句型卡的連接線只替畫面附近的卡片畫）；測驗頁、首頁、使用教學的連結帶 `#points` 會自動展開。
- **隱私說明更新**：`privacy.html` 與使用教學原本說「不登入時沒有對外連線」，補上「選擇語音辨識時 Chrome 會送 Google」。
