## 原因與變更前後

新增 v2 完整學習群組備份與還原控制器，原始 v1 UI 未切換前仍使用原入口。review 指出兩個契約缺口：prepared 題次缺少 session 題面仍可通過匯入；匯出先把不應攜出的本機收據算進10 MiB，會錯誤拒絕可攜內容很小的資料。

修復要求：驗證計畫與 session 題序及保存題面內容一致；只對排除本機 operations 後的真正輸出計算大小，不改動來源資料、不放寬真正輸出的上限。代碼超限的 UI 必須顯示具體原因，而非一律要求回報未知錯誤。

## 規則與取捨

- stats/progress/learning 整組接受或拒絕；偏好可獨立救回並明示錯誤。
- v0/v1 保留摘要、初始化新群組，不偽造過往事件；必須明示完整替換而非合併。
- 本機收據不可跨裝置重播；排除它不能刪掉真實作答事件。
- 還原分預覽與確認，使用 epoch/revision 檢查過期，重試保留 operationId；偏好與學習群組的結果分開回報。
- 不傳送真實資料至網路；Google 與原生儲存未在此階段驗收。
