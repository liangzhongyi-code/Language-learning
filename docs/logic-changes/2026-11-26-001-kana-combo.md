## 規則、邊界與取捨

- **題目來源**：只用第一級（N5）單字，不另造詞表；練過的詞在單字題會再遇到。
  片假名詞（`target` 全是片假名）考片假名寫法，其餘考平假名 `reading`。
- **只收規則對得上的詞**：`kanaToRomaji` 與產生題庫 romaji 的工具（`openspec/tools/kana-romaji.mjs`）同一套規則，
  轉出的羅馬音與題庫 `romaji` 不一致的詞不出題（目前 N5 全部一致）。
- **長音的認定**：ー，或 お段＋う、え段＋い、同母音連寫。動詞結尾的う（おもう、かう）是活用語尾，不算。
  え段＋い 解說寫「通常」拉長。
- **羅馬音寫法**：沿用題庫的照字母寫法（gakkou、sensei、koohii），解說說明實際唸法（gakkō）。
  英文常見的 shoyu、Tokyo 這類省略長音的寫法，在本題型是錯誤選項，解說會交代原因。
- **不能兩個答案都對**：四個選項以羅馬音去重，改完同音的不採用。全部題目、兩個方向、三組亂數都在測試裡逐題掃過。
- **看漢字選讀音**：題面是漢字詞，選項是平假名讀音；模式那排收起來。朗讀用假名，避免語音引擎把漢字唸錯。
  對照表頁與設定說明交代：漢字有音讀／訓讀，也有整個詞一起唸的（今日 きょう），要連同詞一起記。
- **作答前不給朗讀、作答前翻小抄記成用過提示**：與單一假名相同。
- **切回單一假名**：方向是「看漢字選讀音」時退回看假名選羅馬音（單一假名沒有這個方向）。
- **偏好**：題型、組合規則不存偏好，理由同 2026-11-24-001（備份偏好是白名單）。
